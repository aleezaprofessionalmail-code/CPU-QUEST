# CPU QUEST

**An 8086 Assembly-Based Sliding Tiles Puzzle Game and CPU Architecture Learning Simulator**

## About the Project

CPU QUEST is a university semester project that combines an interactive 4×4 sliding tiles puzzle game with an educational CPU architecture dashboard.

The project aims to help students understand fundamental CPU concepts through practical demonstrations and visual simulations.

## Main Modules

- **Assembly Game:** A 4×4 sliding tiles puzzle implemented using 8086 Assembly Language.
- **CPU Architecture Lab:** Educational demonstrations of registers, ALU, memory and instruction execution.
- **CPU Dashboard:** Interactive visual interface for understanding CPU operations.
- **Performance Lab:** Educational cache, pipeline and hazard simulations.

## Technology Stack

- NASM – 8086 Assembly Language
- DOSBox – Running the 16-bit Assembly program
- Python – Backend development
- Flask – Backend framework
- HTML, CSS and JavaScript – Frontend
- SQLite – Local database
- Git and GitHub – Version control

## Project Status

Currently in the initial setup and development phase.

## Learning Objective

To make CPU architecture and Assembly Language easier to understand through an interactive educational application.
